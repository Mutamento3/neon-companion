# 模型 logo 素材

| 文件 | 用途 |
|---|---|
| claude.svg / claude-color.svg | Claude（单色 / 原色） |
| openai.svg | ChatGPT / OpenAI（单色） |
| deepseek.svg / deepseek-color.svg | DeepSeek（单色 / 原色） |
| gemini.svg / gemini-color.svg | Gemini（单色 / 原色） |

- 单色版用 `currentColor`，会跟着主题色变；原色版保留品牌色。
- 来源：LobeHub Icons（`@lobehub/icons-static-svg` 1.102.0，MIT）。各 logo 的商标归各自公司所有，这里只用来标明「接的是哪个模型」。
- 想换成别的模型：放一张 24×24 的 SVG 进这个文件夹，在 `js/util.js` 的 `N.LOGOS` 里加一行，再把 `profile.logo` 改成它的文件名。
